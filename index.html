手调 vs 参数化

同样一个卡片，两种做法的差别

手调 CSS

  • padding 散落各处，改一处漏三处
  • 断点靠试，宽度写死 375px
  • 动效时长随手填，节奏不统一
  • 改完只能靠截图肉眼看

PixelTuner

  • token 统一管理，改一处全站生效
  • clamp + auto-fit 自适应，无写死宽度
  • 动效曲线与时长统一为变量
  • 三档断点实时对照验收
