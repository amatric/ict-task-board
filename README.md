# 2D 沙盒世界 · TerraSandbox

华为 ICT 大赛云赛道 **赛题3（码道开发泰拉瑞亚风格 2D 沙盒游戏）** 的参评作品。

纯前端单文件实现，无依赖、无构建，双击 `index.html` 即可游玩。

## 玩法

| 操作 | 说明 |
|:--|:--|
| `A` / `D` 或 `←` `→` | 左右移动 |
| `空格` / `W` / `↑` | 跳跃 |
| **鼠标左键** | 挖掘方块（进入背包） |
| **鼠标右键** | 放置当前选中的方块（消耗背包） |
| `1`~`5` 或 滚轮 | 切换要放置的方块 |

## 已实现的核心机制

- **程序化地形生成**：带噪声起伏的地表、草皮层 / 泥土层 / 石层分层，随机矿脉、树木、沙地
- **瓦片地图渲染**：64×36 瓦片世界，天空渐变，按可视区域裁剪绘制
- **AABB 碰撞检测**：水平 / 垂直分轴解算，支持站立、跳跃、落地判定
- **挖掘与建造**：左键挖、右键放，带**可达距离限制**（6 格），放置时检测与玩家的重叠
- **背包系统**：方块数量统计，挖掘入包、放置扣包
- **快捷栏**：数字键 / 滚轮切换，实时显示每种方块余量
- **相机跟随**：随玩家平滑滚动，并限制在世界边界内

## 运行

```bash
# 直接打开
open index.html

# 或起本地静态服务
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 技术说明

- 原生 Canvas 2D + requestAnimationFrame，无第三方库
- 世界数据为二维数组 `map[y][x]`，方块类型用常量枚举
- 物理以 60fps 为基准做时间步归一化（`dt` 缩放）
